# Schriften für den Leitspruch

Nur die Zeichen von „一期一会“ und „Ichi-go ichi-e“, als Teilmenge von Google Fonts geladen.
In der App heißen sie „SK Kanji“ und „SK Pinsel“.

- `yuji-syuku.woff2` – Yuji Syuku, SIL Open Font License 1.1 (`OFL-yuji-syuku.txt`)
- `kaushan-script.woff2` – Kaushan Script, SIL Open Font License 1.1 (`OFL-kaushan-script.txt`)
